# Changelog

## 0.2.0 (2026-11-20)

- Requires Paseo 0.15 or later: uses its renamed plugin hooks (the old ones are removed after 2027-04-30).
- Built against the Paseo 0.16 plugin SDK; tested on Paseo 0.16.2.

## 0.1.0 (2026-10-30)

First version.

- Chats without a project, from the sidebar or the command center, listed in one place.
- Connect a chat to a project later: its conversation carries over to a new agent there.
- Pick an open project or search for any folder, on every drive; spaces, "-", "_" and capitals don't matter.
- Works in Paseo's desktop, web and mobile apps.
